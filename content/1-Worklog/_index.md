**Trong trang này** bạn sẽ cần giới thiệu worklog của bạn **như thế nào**? Bạn hoàn thành chương trình trong vòng **bao nhiêu tuần**? Bạn **đã làm gì** trong các tuần đó?


Thông thường và cũng là tiêu chuẩn, một worklog được thực hiện trong khoảng 3 tháng (trong suốt thời gian thực tập) với nội dung các tuần như sau:

**Tuần 1:** [Làm quen với AWS và các dịch vụ cơ bản trong AWS](1.1-week1/)

**Tuần 2:** [Học các dịch vụ cơ bản: EC2, S3, VPC; triển khai máy chủ EC2 đầu tiên](1.2-week2/)

**Tuần 3:** [Thực hành quản lý lưu trữ với Amazon S3, cấu hình quyền truy cập và Bucket Policy](1.3-week3/)

**Tuần 4:** [Tìm hiểu cơ sở dữ liệu trên AWS: RDS, DynamoDB; kết nối ứng dụng với database](1.4-week4/)

**Tuần 5:** [Học về Networking: VPC, Subnet, Route Table, Internet Gateway, Security Group và NACL.](1.5-week5/)

**Tuần 6:** [Triển khai ứng dụng web trên EC2 kết hợp RDS; cấu hình Load Balancer cơ bản.](1.6-week6/)

**Tuần 7:** [Tìm hiểu Auto Scaling, Elastic Load Balancer và tối ưu khả năng mở rộng hệ thống.](1.7-week7/)

**Tuần 8:** [Làm việc với dịch vụ Serverless: AWS Lambda, API Gateway và EventBridge.](1.8-week8/)

**Tuần 9:** [Xây dựng CI/CD bằng CodeCommit, CodeBuild, CodeDeploy hoặc GitHub Actions kết hợp AWS.](1.9-week9/)

**Tuần 10:** [Theo dõi hệ thống với CloudWatch, CloudTrail; cấu hình cảnh báo và thu thập log.](1.10-week10/)

**Tuần 11:** [Hoàn thiện dự án nhóm, tối ưu chi phí bằng AWS Cost Explorer và AWS Budgets; kiểm thử toàn bộ hệ thống.](1.11-week11/)

**Tuần 12:** [Demo dự án, báo cáo kết quả, tổng kết kiến thức, đánh giá và rút kinh nghiệm từ quá trình thực hiện.](1.12-week12/)
